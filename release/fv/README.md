# FirstVoices Keyman Keyboards

Welcome to the official repository for FirstVoices Keyman keyboards. This repository contains the source files for keyboards developed by the FirstVoices team to support Indigenous languages across Canada and beyond.

## About FirstVoices

FirstVoices is an online space for communities to share and promote their language, oral traditions, and culture. It is an initiative of the First Peoples' Cultural Council (FPCC).

## About Keyman

Keyman is a free, open-source keyboard utility available for Windows, macOS, Linux, iOS, Android, and the web. It allows users to type in hundreds of languages using customized keyboard layouts.

## Getting Started

To use these keyboards, you will need to install Keyman on your device.

1. **Download Keyman:** Visit the [Keyman Website](https://keyman.com) to download the software for your operating system.
2. **Install a Keyboard:** Search for your language community's keyboard directly through the Keyman app or on the FirstVoices website.

## Repository Structure

* `/release`: Contains production-ready keyboard layouts.
  * `/fv`: Dedicated directory for FirstVoices-specific language keyboards (e.g., `fv_secwepemctsin`, `fv_hulquminum`).
* `/development`: Contains keyboards currently in development or testing phase.
* `/shared`: Contains shared resources, fonts, and documentation used across multiple keyboards.

## Contribution Guidelines

We welcome contributions to improve existing keyboards or add support for new languages. 

1. **Fork the Repository:** Create a personal fork of this repository.
2. **Create a Branch:** Create a branch for your specific keyboard changes.
3. **Follow Keyman Standards:** Ensure your keyboard source code adheres to the [Keyman Keyboard Packaging Guidelines](https://keyman.com).
4. **Submit a Pull Request:** Submit your pull request against the `master` or `development` branch for review.
