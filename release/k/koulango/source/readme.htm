Clavier Koulango

Le clavier Koulango permet d’écrire le koulango avec son orthographe latine standardisée sur les téléphones, tablettes et ordinateurs compatibles avec Keyman.

Sur les écrans tactiles, les lettres particulières du koulango sont directement visibles. Lorsqu’un clavier physique ou externe est utilisé, elles sont accessibles avec la touche AltGr.

Caractères pris en charge

ɛ ɔ ɩ ʋ ɲ ŋ

Ɛ Ɔ Ɩ Ʋ Ɲ Ŋ

Ces lettres sont de véritables caractères Unicode. Elles peuvent être utilisées dans les messages, documents, sites Internet et applications compatibles avec Unicode.

q s d f g h j k l m ɛ
w c v b n ɩ ʋ ɲ ŋ

Disposition tactile majuscule

Touches particulières sur écran tactile

  • Un appui long sur c donne accès à x.
  • Un appui long sur C donne accès à X.
  • La touche 123 donne accès aux chiffres et aux symboles.
  • La touche Majuscule donne accès aux lettres capitales.

Utilisation avec un clavier physique

Lorsqu’un clavier physique est utilisé sur un ordinateur, un téléphone ou une tablette, maintenez la touche AltGr et appuyez sur la lettre latine correspondante.

Combinaison Résultat
AltGr + E ɛ
AltGr + O ɔ
AltGr + I ɩ
AltGr + U ʋ
AltGr + N ɲ
AltGr + G ŋ

Pour produire les lettres majuscules, utilisez Majuscule + AltGr + lettre.

Combinaison Résultat
Majuscule + AltGr + E Ɛ
Majuscule + AltGr + O Ɔ
Majuscule + AltGr + I Ɩ
Majuscule + AltGr + U Ʋ
Majuscule + AltGr + N Ɲ
Majuscule + AltGr + G Ŋ

Sur certains systèmes, la touche AltGr est interprétée comme la combinaison Ctrl + Alt. Dans ce cas, les mêmes lettres peuvent être saisies avec Ctrl + Alt + lettre.

Installation sur téléphone ou tablette

  1. Installez l’application Keyman sur votre appareil.
  2. Recherchez et installez le clavier Koulango.
  3. Activez Keyman comme clavier dans les paramètres de l’appareil.
  4. Sélectionnez le clavier Koulango lorsque vous souhaitez écrire en koulango.

Installation sur ordinateur

  1. Installez la version de Keyman compatible avec votre système.
  2. Recherchez et installez le clavier Koulango.
  3. Sélectionnez le clavier Koulango dans Keyman.
  4. Utilisez AltGr avec la lettre correspondante pour saisir les lettres particulières du koulango.
